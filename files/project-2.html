Campus Map Viewer

An interactive map showing which lecture rooms are free right now, built with two classmates for a software engineering course.

StackJavaScript, Leaflet.js, Node.js RoleFrontend + map logic StatusCourse project, archived

What it does

The map overlays the university's timetable data onto a floor plan, colour-coding rooms as free or occupied for the current time slot. Clicking a room shows its schedule for the rest of the day.

How it's built

Leaflet.js renders the custom floor plan as a tile layer, with room polygons drawn as GeoJSON overlays. A small Node.js service parses the timetable export and serves it as JSON, which the frontend polls every few minutes.

My contribution

  • Built the map interaction layer and room polygon rendering
  • Wrote the free/occupied colour logic and the click-to-inspect panel
  • Set up the CI pipeline that deployed the frontend on every merge
