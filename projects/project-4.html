Autonomous Driving Scenario

A computer vision system for detecting, classifying, and tracking pedestrians, cyclists, and cars in 3D using stereo camera data.

StackPython, OpenCV, YOLOv8, PyTorch RoleComputer Vision & 3D Tracking StatusCourse project, completed

What it does

This project develops a perception pipeline for autonomous driving in dynamic urban environments. The system uses a forward-facing stereo camera to detect and classify pedestrians, cyclists, and cars, estimate their 3D positions, and track them across consecutive frames.

Camera Calibration & Rectification

The first stage of the pipeline calibrates the stereo camera system and rectifies the raw stereo images. Multiple chessboards of different sizes were automatically detected using OpenCV. The resulting camera parameters were used for stereo calibration and image rectification, with epipolar lines used to verify the quality of the transformation.

Depth Estimation

Depth was estimated from the rectified stereo image pairs using OpenCV's StereoSGBM algorithm. Disparity maps were converted into metric depth using the calibrated stereo parameters and refined using filtering and inpainting techniques.

The StereoSGBM parameters were optimized using Optuna, with the mean depth error against the provided ground truth used as the optimization objective.

Object Detection

A YOLOv8 model was fine-tuned to detect the three relevant object classes: pedestrians, cyclists, and cars. Additional public datasets were used to adapt the pretrained model to the specific requirements of the autonomous driving scenario.

3D Object Tracking

Detected objects were assigned 3D positions using the estimated depth information and tracked across video frames using a modified version of ByteTrack.

To improve tracking during occlusions, the tracker was extended with visual re-identification features extracted using a pretrained ResNet-50 model. Spatial and velocity constraints were also added to reduce incorrect matches between objects.

Optimization & Evaluation

Optuna was also used to optimize the tracking parameters for different object classes. The final system was evaluated against ground-truth annotations using precision, recall, and multi-object tracking metrics.

The results showed that the system could reliably detect and track objects in realistic urban scenes, although heavy occlusion and interactions between pedestrians and cyclists remained challenging.

Project Results

The project resulted in a complete perception pipeline combining stereo vision, depth estimation, deep-learning-based object detection, and 3D multi-object tracking. The system was tested on multiple driving sequences, including an unlabelled sequence for qualitative evaluation under realistic conditions.
