MAMBA for EHR Classification

Implementation and evaluation of a MAMBA-based structured state space model for mortality prediction from electronic health records.

StackPython, PyTorch, MAMBA RoleUniversity project Course02456 Deep Learning, DTU

What it does

This project implements a version of the MAMBA structured state space model for classifying electronic health records. The model is trained to predict in-hospital mortality using the PhysioNet 2012 Challenge dataset, which contains multivariate clinical time series from intensive care unit patients.

How it's built

The model was implemented in PyTorch and evaluated using the Area Under the Precision-Recall Curve (AUPRC) and Area Under the Receiver Operating Characteristic Curve (AUROC). The project also includes several baseline architectures, including Transformer, SeFT, GRU-D and IP-Nets, allowing the performance of the MAMBA-based approach to be compared with established models for EHR classification.

What I learned

  • Implementing and working with structured state space models
  • Adapting existing model implementations to different input formats by changing how the model processes and manipulates the input rather than modifying the underlying data
  • Applying deep learning models to multivariate medical time series
  • Evaluating sequence models using AUROC and AUPRC
  • Understanding the differences between SSMs and attention-based models
