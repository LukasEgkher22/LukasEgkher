Habit Tracker API

A REST API for logging daily habits and computing streaks, built to learn FastAPI and proper database migrations.

StackPython, FastAPI, PostgreSQL, Docker RoleSolo project StatusActively maintained

What it does

Users can create habits, log completions, and query current and longest streaks. The API handles timezone-aware date logic so a streak doesn't break just because someone logs in after midnight in their own timezone.

How it's built

The backend is FastAPI with Pydantic models for request and response validation. Data lives in PostgreSQL, accessed through SQLAlchemy, with Alembic handling schema migrations. The whole stack runs in Docker Compose for local development.

What I learned

  • Designing a clean, versioned REST API surface
  • Handling timezone edge cases correctly instead of guessing
  • Writing integration tests against a real test database
